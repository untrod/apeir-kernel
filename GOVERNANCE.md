# Governance

APEIR Kernel is maintained through reviewed changes to code, tests,
specifications, documentation, and architecture decisions.

Maintainers are responsible for merging changes, managing releases, assigning
review ownership, and coordinating security reports. Reviewers may approve
changes in components where they have demonstrated technical ownership.

Decisions prioritize safety invariants, protocol compatibility, reproducible
evidence, maintainability, and a small trusted computing base. Changes to a
public protocol, durable-state interpretation, security boundary, or ownership
rule require an accepted RFC or architecture decision, compatibility analysis,
tests, and explicit maintainer approval. Security work may be reviewed through
a private process until coordinated disclosure.

Project roles and responsibilities are recorded in
[MAINTAINERS.md](MAINTAINERS.md). The contribution process is defined in
[CONTRIBUTING.md](CONTRIBUTING.md).
