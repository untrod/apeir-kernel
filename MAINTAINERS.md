## Responsibilities

The maintainer reviews Kernel changes, protects NKI and compatibility
boundaries, coordinates security reports, and approves releases. Changes to a
public protocol, persistent identity, signed record, or security invariant
require an RFC or equivalent design record and explicit maintainer review.

Use public issues for reproducible non-security defects after the repository is
published. Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Public tags,
uploads, and releases require explicit maintainer approval.
